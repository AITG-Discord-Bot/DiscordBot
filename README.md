
## AITG 디스코드 봇

이 저장소는 **AITG 디스코드 봇**의 소스 코드를 포함하고 있습니다.

---

## 디렉토리 구조 🌳

### `/app`
이 디렉토리는 봇의 주요 애플리케이션 코드를 담고 있습니다.

#### `/common`
이곳에는 봇의 여러 부분에서 공통적으로 사용되는 유틸리티와 헬퍼 함수들이 있습니다.
* **RateLimiter.py**: API 요청 속도 제한을 관리합니다. 
* **localization**: 다국어 지원을 위한 로컬라이제이션 관련 파일들이 포함되어 있습니다.
* **error_handler.py**: 봇에서 발생하는 오류들을 처리하는 로직을 담고 있습니다.
* **apirequest.py**: 외부 API 요청을 처리하는 모듈입니다. 
* **var.py**: 봇의 전역 변수들을 정의합니다. 

#### `/Extensions`
이 폴더는 디스코드 봇의 확장 기능을 관리합니다. 각 확장 기능은 고유한 폴더로 분리되어 있습니다.
* **확장 폴더명**: 확장명을 폴더명으로 사용합니다 (예: `Clanwar`).
* **`__init__.py`**: 이 파일은 확장 모듈을 초기화하며, `from .core import setup, teardown`과 같이 필수 함수나 클래스를 임포트합니다. 
* **`core.py`**: 확장 기능의 핵심 로직(명령어 처리, 이벤트 구독 등)이 구현되어 있습니다. 
* **`handler`**: 확장 기능 내에서 발생하는 이벤트들을 처리하는 핸들러 모듈들이 위치합니다.
    * **`button_handler.py`**: 버튼 클릭 이벤트를 처리합니다. 
    * **`user_select_handler.py`**: 사용자 선택 이벤트(명령어 처리)를 담당합니다. 
    * **`string_select_handler.py`**: 문자열 선택 메뉴 이벤트를 처리합니다. 
    * **`channel_select_handler.py`**: 채널 선택 메뉴 이벤트를 처리합니다. 

---

### 기타 주요 파일 📁

* **`main.py`**: 봇의 진입점(entry point)입니다. 
* **`Dockerfile`**: Docker 컨테이너를 빌드하기 위한 파일입니다. 
* **`requirements.txt`**: 봇 실행에 필요한 파이썬 라이브러리 목록이 포함되어 있습니다.
* **`locales/`**: 다국어 지원을 위한 언어 파일들(`en-US.json`, `ko.json` 등)이 저장됩니다.
